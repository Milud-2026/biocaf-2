# BIO CAFE — déploiement

Le site est une application Next.js prête à être publiée depuis GitHub.

## GitHub

1. Créez un dépôt vide sur GitHub.
2. Ajoutez ce projet au dépôt et poussez la branche `main`.

## Vercel

1. Dans Vercel, choisissez **Add New → Project**.
2. Importez le dépôt GitHub.
3. Vercel détectera automatiquement Next.js et utilisera `vercel.json`.
4. Cliquez sur **Deploy**. Aucune variable d’environnement n’est nécessaire.

Pour connecter un nom de domaine, ouvrez ensuite **Project Settings → Domains**.
